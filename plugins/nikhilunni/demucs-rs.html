demucs-rs v0.3.4

By Nikhil Unni

Native Rust implementation of HTDemucs v4 for music source separation. Splits a song into stems (drums, bass, vocals, other) using GPU-accelerated inference, as a native CLI or a DAW plugin (VST3/CLAP on macOS).
