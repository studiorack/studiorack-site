Scyclone v0.0.3

By Torsion Audio

Real-time neural timbre transfer plugin using RAVE models, letting you morph the timbre of live or recorded audio into a trained target sound in real time. Code is GPLv3; bundled pretrained ONNX models are CC BY-NC 4.0 (non-commercial).
